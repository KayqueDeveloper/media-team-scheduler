# Publicação Versionada com Alertas

Uma escala passa por Rascunho e Publicada, podendo ser reaberta explicitamente para edição. Cada publicação preserva uma versão histórica. Vagas descobertas e outros alertas de cobertura não bloqueiam a publicação, mas exigem confirmação explícita do líder e ficam associados à versão publicada. PDFs oficiais e compartilhamento para a equipe só são liberados para versões publicadas; rascunhos podem gerar apenas prévias identificadas.
